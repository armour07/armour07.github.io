## 新建文章

打开命令行
```
hexo new "文章标题"
```

创建完成之后，打开 `source/_posts` 文件夹，可以看到新建的文章。

## 发布文章

```
git add *
git commit -m "提交信息"
git push
```

github 通过 webhook 自动部署，文章发布（workflows/pages.yml）。

## 增加预览背景图

1. 图片存放在 `source/img/default-cover-bg-n.jpg`
2. 修改配置文件 `_config.butterfly.yml`，`cover->default_cover->default-cover-bg-n.jpg`
